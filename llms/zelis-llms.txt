# Zelis

> Zelis is a healthcare financial technology company that modernizes the business of healthcare by connecting payers, providers, and members. It exposes partner-facing capabilities — claims document search/view, member ID card search/view, provider directory, enrollment, payments, and member-engagement communications — through a public developer portal and API marketplace, gated behind OAuth2 client-credential tokens plus an Azure API Management subscription key.

## API

- [Zelis API](https://developer.zelis.com/): partner-facing healthcare payments, claims, ID card, provider directory, and communications APIs. Base URL https://api.zelis.com/.

## Authentication

- OAuth2 client-credentials grant. Token endpoint: https://api.zelis.com/auth/token (POST). Token TTL 3600s.
- Every request ALSO requires an Azure API Management subscription key in the `Ocp-Apim-Subscription-Key` header.
- HTTPS-only, JSON payloads.
- Authentication profile: authentication/zelis-authentication.yml
